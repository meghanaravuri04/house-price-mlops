 # House Price Prediction - MLOps Project

## Project Overview

This project predicts house prices using
Machine Learning and MLOps technologies.

## Technologies

- Python
- Pandas
- Scikit-learn
- Git and GitHub
- DVC
- DagsHub
- MLflow
- FastAPI
- Streamlit
- Docker
- AWS ECR
- AWS EC2
- GitHub Actions

## Machine Learning Algorithm

Random Forest Regressor

## Dataset Features

- Area
- Bedrooms
- Bathrooms
- House Age
- Location Score

Target:
- House Price

## Project Structure

src/          - ML source code
data/         - Dataset
models/       - Trained model
metrics/      - Evaluation metrics
app/          - FastAPI backend
tests/        - Unit tests

## Applications

FastAPI:
Provides prediction endpoints.

Streamlit:
Provides interactive user interface.

## MLOps Features

- Data versioning using DVC
- Experiment tracking using MLflow
- Remote tracking using DagsHub
- Containerization using Docker
- CI/CD using GitHub Actions
- Cloud deployment using AWS

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R2 Score
